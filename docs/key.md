# เว็บไซต์ต้นแบบ คณะวิทยาศาสตร์การกีฬา ม.บูรพา

งานกลุ่ม 5 คน วิชาการสร้างสรรค์เว็บไซต์สำหรับงานกีฬา นำเสนอ 28 ต.ค. 2569
ผู้ใช้โปรเจกต์เป็นมือใหม่ ให้อธิบายเป็นภาษาไทยง่าย ๆ และเขียนคอมเมนต์ภาษาไทยในโค้ด

## เทคโนโลยี
- HTML, CSS, JavaScript ล้วน ไม่ใช้เฟรมเวิร์ก
- Supabase (ฐานข้อมูล, Login, เก็บรูป) เรียกผ่าน supabase-js จาก CDN
- Deploy ด้วย Vercel/Netlify, โค้ดอยู่บน GitHub

## กติกาที่ห้ามละเมิด
- Mobile-First ห้ามเลื่อนแนวนอนที่ 375px
- ฟอนต์ Noto Sans Thai, line-height 1.7, ตัวอักษร ≥ 16px, ปุ่ม ≥ 44px
- เมนูหลัก ≤ 7 รายการ ข้อมูลที่ใช้บ่อยเข้าถึงภายใน 3 คลิก
- ห้ามฝังข้อมูลใน HTML ข้อมูลต้องมาจากฐานข้อมูล
- ห้ามใส่ service_role key หรือรหัสผ่านในโค้ด ใช้เฉพาะ anon key
- ห้ามแต่งข้อมูลจริงของคณะ (ชื่ออาจารย์ ทุน เบอร์โทร) ใช้ข้อมูลตัวอย่างและทำเครื่องหมายไว้
- ทำทีละหน้า แล้วหยุดรอให้ตรวจ

## เอกสารอ้างอิง (อ่านก่อนทำงาน)
- docs/assignment.md โจทย์และเกณฑ์คะแนน
- docs/requirements.md ผลแบบสอบถามและข้อจำกัด
- docs/sitemap.md เมนูและโครงหน้าเว็บ
- docs/style-guide.md สี ฟอนต์ ปุ่ม การ์ด
- docs/database_schema.md โครงสร้างฐานข้อมูลและแหล่งที่มาของข้อมูลจริง
- docs/setup-supabase.md วิธีติดตั้งและเชื่อมฐานข้อมูล Supabase

## สถานะปัจจุบัน
- หน้าที่สร้างแล้ว: index, news, news-detail, sports-news, sports-news-detail
- ข้อมูล: มีฐานข้อมูลจริงแล้วที่ supabase/ (schema.sql + seed.sql) และสำเนาใน js/sample-data.js
- ยังไม่ได้ทำ: หน้าหลักสูตร/อาจารย์, หน้าทุน, หน้าผลงาน/คลังสื่อ, หน้าติดต่อ, ระบบ Admin ทั้งหมด
