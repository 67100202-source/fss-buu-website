# คู่มือแนวทางการออกแบบและอัตลักษณ์สายตา (Style Guide & Visual System)

เอกสารฉบับนี้กำหนดมาตรฐานการออกแบบส่วนติดต่อผู้ใช้ (UI Design System) สำหรับเว็บไซต์ต้นแบบคณะวิทยาศาสตร์การกีฬา มหาวิทยาลัยบูรพา (`BUU | FSS`) โดยพัฒนาขึ้นจากผลโหวตโทนสี/สไตล์ในแบบสอบถามข้อ 11 (ทันสมัย/มินิมอล 60% และเป็นทางการ/สุภาพ 40%) ผสานกับอัตลักษณ์ของมหาวิทยาลัยบูรพาและคณะวิทยาศาสตร์การกีฬา รวมถึงการนำ **ข้อเสนอแนะเชิงลึกของผู้ตอบแบบสอบถามคนที่ 5** มาแปลงเป็นเกณฑ์การออกแบบอย่างเป็นรูปธรรม

## 1. ระบบสีประจำเว็บไซต์ (Color Palette: เหลืองทอง เขียว เทา และขาว)

ทีมเลือกใช้โครงสร้างสีที่สะท้อนอัตลักษณ์ของทั้ง **มหาวิทยาลัยบูรพา (สีเหลืองทอง - เทา)** และ **คณะวิทยาศาสตร์การกีฬา (สีเขียว)** บนพื้นหลังสีขาวสะอาดตาตามสไตล์มินิมอล เพื่อช่วยแยกหมวดหมู่ข้อมูลให้ชัดเจนและอ่านง่ายบนหน้าจอมือถือ

| กลุ่มสี | ชื่อตัวแปร CSS (Token) | รหัสสี (Hex Code) | บทบาทและการนำไปใช้งานจริงบนหน้าเว็บ |
| :--- | :--- | :---: | :--- |
| **สีเหลืองทอง (Gold / Yellow)** | `--color-yellow` | `#D9A404` | **สีอัตลักษณ์ ม.บูรพา (BUU):** ใช้เน้นข้อความโลโก้ `BUU`, แถบสีหน้าหัวข้อหมวดหมู่สำคัญอันดับ 1 (ปฏิทินการศึกษา), เส้นขอบซ้ายของการ์ดกิจกรรม และปุ่มแท็บที่กำลังเลือก (Active Tab) |
| **สีเหลืองทองอ่อน (Soft Gold)** | `--color-yellow-soft` | `#FEF9E7` | ใช้เป็นสีพื้นหลังอ่อนสำหรับกล่องแจ้งเตือนประกาศด่วน หรือไฮไลต์กำหนดการสำคัญ |
| **สีเขียว (Sport Science Green)** | `--color-green` | `#1B6B45` | **สีอัตลักษณ์คณะวิทย์กีฬา (FSS):** ใช้เน้นข้อความโลโก้ `FSS`, แถบสีหน้าหัวข้อหมวดข่าวสารและกิจกรรม, ป้ายกำกับข่าว (`[ข่าว]`), สีเวลาเรียน, เส้นขอบการ์ดเมื่อผู้ใช้แตะเลือก (Focus/Active) และปุ่มกดหลัก |
| **สีเขียวอ่อน (Soft Green)** | `--color-green-soft` | `#ECFDF5` | ใช้เป็นสีพื้นหลังเมื่อผู้ใช้แตะหรือชี้ปุ่มเมนู/การ์ดข่าว (Hover / Active State) เพื่อช่วยให้เห็นสถานะการกดชัดเจน |
| **สีเทาเข้ม (Dark Gray)** | `--color-gray-dark` | `#1F2937` | ใช้สำหรับ **ตัวอักษรหลักและหัวข้อทั้งหมด** ให้ค่าความเปรียบต่าง (Contrast) สูงกว่ามาตรฐาน WCAG AA อ่านสบายตากว่าสีดำสนิท |
| **สีเทากลาง (Medium Gray)** | `--color-gray-medium` | `#4B5563` | ใช้สำหรับ **ข้อความรอง** เช่น คำอธิบายย่อ สถานที่เรียน วันที่อัปเดต และแถบสีหน้าหมวดหมู่รอง |
| **สีเทาอ่อน (Light Gray Border)** | `--color-gray-light` | `#E5E7EB` | ใช้สำหรับ **เส้นขอบการ์ด (Card Border)** เส้นคั่นส่วนหัวเว็บ และเส้นกรอบปุ่มกด ช่วยแยกก้อนข้อมูลออกจากกันอย่างมีระเบียบ |
| **สีเทาพื้นหลัง (Background Gray)** | `--color-gray-bg` | `#F9FAFB` | ใช้สำหรับพื้นหลังการ์ดย่อย (เช่น รายการวิชาเรียน รายการหลักสูตร/ทุน) และพื้นหลังส่วนท้ายเว็บ (Footer) |
| **สีขาว (Pure White)** | `--color-white` | `#FFFFFF` | ใช้เป็น **พื้นหลังหลักของหน้าเว็บและการ์ดหลัก** สื่อถึงความสะอาดตา ทันสมัย และมินิมอลตามผลโหวตอันดับ 1 (60%) |

## 2. ระบบตัวอักษรและฟอนต์ภาษาไทย (Typography)

เพื่อแก้ปัญหาเรื่องตัวหนังสืออ่านยากและสระ/วรรณยุกต์ภาษาไทยซ้อนทับกันบนหน้าจอมือถือ ทีมได้กำหนดมาตรฐานฟอนต์ดังนี้

- **ฟอนต์หลัก (Primary Font Family):** `'Noto Sans Thai', -apple-system, BlinkMacSystemFont, sans-serif` (ดึงจาก Google Fonts) เนื่องจากเป็นฟอนต์ตระกูลไม่มีหัวยุคใหม่ (Modern Looped/Loopless-friendly Sans-Serif) ที่ออกแบบมาให้อ่านภาษาไทยและภาษาอังกฤษร่วมกันได้ชัดเจนในทุกขนาดหน้าจอ
- **ขนาดตัวอักษรขั้นต่ำ (Minimum Font Size Floor):** กำหนดขนาดพื้นฐานที่ **`16px` (`1rem`)** สำหรับข้อความทุกจุดบนหน้าจอมือถือ (ห้ามใช้ฟอนต์เล็กกว่า 16px เด็ดขาด) เพื่อให้อ่านง่ายโดยไม่ต้องถ่างนิ้วซูม และป้องกันเบราว์เซอร์บน iOS ซูมหน้าจอเองเวลาแตะช่องค้นหา
- **ระยะห่างระหว่างบรรทัด (Line Height):** กำหนด **`line-height: 1.7`** ในทุกองค์ประกอบข้อความ เพื่อป้องกันไม่ให้สระบน-ล่างและวรรณยุกต์ภาษาไทยชนหรือซ้อนทับกัน
- **การตัดคำ (Word Wrapping):** ใช้ `overflow-wrap: break-word` ร่วมกับการจัดความยาวข้อความให้กระชับ เพื่อป้องกันข้อความทะลุกรอบการ์ดหรือล้นขอบจอแนวนอน

| ระดับข้อความ (Text Element) | ขนาดฟอนต์ (Size) | น้ำหนักฟอนต์ (Weight) | สีที่ใช้ (Color) | การนำไปใช้ |
| :--- | :---: | :---: | :--- | :--- |
| **โลโก้เว็บไซต์ (`BUU | FSS`)** | `18px` (`1.125rem`) | `700` (Bold) | `#D9A404` / `#1B6B45` | มุมซ้ายบนของส่วนหัวเว็บไซต์ (Header) |
| **หัวข้อหมวดหมู่หลัก (`Section Title`)** | `16.8px` (`1.05rem`) | `700` (Bold) | `#1F2937` (เทาเข้ม) | หัวข้อใหญ่ของการ์ดแต่ละหมวด เช่น ข่าวสารล่าสุด |
| **หัวข้อรายการย่อย (`Card / Item Title`)** | `16px` (`1.00rem`) | `600` (Semi-Bold) | `#1F2937` (เทาเข้ม) | ชื่อวิชาเรียน, หัวข้อข่าว, ชื่อหลักสูตร, ชื่อประกาศทุน |
| **ป้ายกำกับและเวลา (`Tag / Time Badge`)** | `16px` (`1.00rem`) | `700` (Bold) | `#1B6B45` (เขียว) | ป้าย `[ข่าว 1]`, เวลาเรียน `09:00-11:00` หน้าหัวข้อย่อย |
| **เนื้อหาและคำอธิบายรอง (`Body / Meta`)** | `16px` (`1.00rem`) | `400–500` (Regular/Medium) | `#4B5563` (เทากลาง) | รายละเอียดข่าว, ห้องเรียน, คำอธิบายหลักสูตร และข้อความส่วนท้าย |

## 3. ขนาดปุ่มกดและมาตรฐานพื้นที่สัมผัสบนมือถือ (Button Sizes & Touch Targets)

เนื่องจากผู้ตอบแบบสอบถามใช้อุปกรณ์พกพา 100% (มือถือ 60%, แท็บเล็ต 40%) และพบปัญหาการแสดงผลบนมือถือไม่ดี ทีมจึงกำหนดขนาดปุ่มและพื้นที่กดทุกจุดให้มีขนาด **ไม่ต่ำกว่า `44x44px`** ตามมาตรฐานสากลของ Mobile UX (Apple HIG / WCAG Touch Target)

| ประเภทปุ่ม / พื้นที่กด | ขนาดขั้นต่ำ (Width × Height) | มุมโค้ง (Border Radius) | รูปแบบและสถานะการตอบสนอง (Visual & Interactive State) |
| :--- | :---: | :---: | :--- |
| **ปุ่มไอคอนส่วนหัว (ค้นหา & เมนู Hamburger)** | **`44px × 44px`** | `10px` | พื้นหลังขาว กรอบสีเทาอ่อน `#E5E7EB` เมื่อแตะหรือเปิดใช้งานจะเปลี่ยนพื้นหลังเป็นสีเขียวอ่อน `#ECFDF5` และกรอบ/ไอคอนเป็นสีเขียว `#1B6B45` |
| **ปุ่มเมนูหลักแนวตั้ง (Vertical Menu Links)** | **กว้าง `100%` × สูงอย่างน้อย `48px`** | `8px` | พื้นหลังเทาอ่อน `#F9FAFB` มีแถบสีเขียวด้านซ้ายหนา `4px` พร้อมลูกศร `→` ด้านขวา กดง่ายด้วยนิ้วโป้งมือเดียว |
| **ปุ่มเลือกชั้นปี (`ปี 1` – `ปี 4`)** | **กว้างเฉลี่ยเท่ากัน (`min-width: 44px`) × สูง `44px`** | `8px` | ปุ่มที่ถูกเลือก (Active) จะเปลี่ยนพื้นหลังเป็นสีเหลืองทอง `#D9A404` ตัวอักษรสีเทาเข้มหนา (`font-weight: 700`) เห็นชัดเจนทันทีว่ากำลังดูหมวดหมู่ใด |
| **ช่องพิมพ์ค้นหาและปุ่มล้างคำค้น (`✕`)** | **ช่องพิมพ์สูง `44px` / ปุ่มล้าง `44px × 44px`** | `8px` | เมื่อแตะพิมพ์ กรอบช่องค้นหาจะเปลี่ยนเป็นสีเขียว `#1B6B45` และแสดงปุ่ม `✕` ขนาด `44x44px` ด้านขวาเพื่อกดลบคำค้นได้แม่นยำ |
| **การ์ดข่าวสารที่แตะเปิดอ่านได้ (`News Card`)** | **กว้าง `100%` × สูงอย่างน้อย `44px`** | `8px` | ตีกรอบรอบด้านด้วยสีเทาอ่อน `#E5E7EB` และคาดแถบซ้ายสีเขียวหนา `4px` แตะที่การ์ดเพื่อกางดูรายละเอียดข่าวเพิ่มเติมได้ทันที |

## 4. การนำข้อเสนอแนะของผู้ตอบคนที่ 5 มาปรับใช้ในการออกแบบโดยตรง

ในแบบสอบถามข้อ 14 (สิ่งที่อยากให้ปรับปรุงมากที่สุดในเว็บไซต์คณะ) **ผู้ตอบคนที่ 5 (นิสิตปัจจุบัน ชั้นปีที่ 3)** ได้ให้ข้อเสนอแนะเชิงลึกด้านการออกแบบสายตา (Visual Design) ไว้อย่างชัดเจนดังนี้:

> *"ไม่ชอบ font รู้สึกอ่านยาก จัดวางหัวข้อไม่น่าสนใจ ควรเพิ่้ม icon หน้าหัวข้อดูแบบวางเป็นกองๆ กลืนกับหัวใหญ่อ่านยากไม่เด่นควรเพิ่มสีมีกรอบให้ข้อความ"*

ทีมได้นำข้อเสนอแนะของผู้ตอบคนที่ 5 มาแยกวิเคราะห์เป็น 4 ปัญหาหลัก และกำหนดเป็นกฎการออกแบบ (Design Rules) ใน Style Guide ฉบับนี้ครบทุกประเด็น:

| ข้อเสนอแนะของผู้ตอบคนที่ 5 | แนวทางการแก้ไขและกฎการออกแบบใน Style Guide |
| :--- | :--- |
| **1. "ไม่ชอบ font รู้สึกอ่านยาก"** | เปลี่ยนมาใช้ฟอนต์ **Noto Sans Thai** ที่มีหัวชัดเจนและโครงสร้างโปร่งสบายตา กำหนดขนาดตัวอักษรขั้นต่ำ **`16px`** ทุกจุด และตั้งค่าระยะบรรทัด **`line-height: 1.7`** เพื่อไม่ให้ตัวหนังสือเบียดหรือสระซ้อนทับกัน |
| **2. "จัดวางหัวข้อไม่น่าสนใจ ... กลืนกับหัวใหญ่อ่านยากไม่เด่น"** | สร้างลำดับขั้นของหัวข้อ (Visual Hierarchy) ให้ชัดเจน โดยแยกขนาดและน้ำหนักของหัวข้อหมวดหมู่ใหญ่ (`1.05rem`, `Bold 700`) ออกจากหัวข้อรายการย่อย (`1.00rem`, `Semi-Bold 600`) และคำอธิบายรอง (`#4B5563`) พร้อมใส่ป้ายกำกับสีเขียว (`[ข่าว 1]`, เวลาเรียนสีเขียว `09:00-11:00`) นำหน้าหัวข้อย่อยเพื่อดึงสายตา |
| **3. "ควรเพิ่ม icon หน้าหัวข้อ"** | เพิ่ม **แถบสัญลักษณ์สีหน้าหัวข้อ (Priority Indicator / Visual Icon Badge)** ขนาด `4px × 18px` และสัญลักษณ์นำสายตาหน้าหัวข้อทุกหมวด โดยแยกสีตามความสำคัญ (สีเหลืองทอง `#D9A404` สำหรับหมวดปฏิทินกิจกรรม, สีเขียว `#1B6B45` สำหรับหมวดข่าวสาร, และสีเทา `#4B5563` สำหรับหมวดหลักสูตรและทุน) รวมถึงใช้ไอคอน SVG คมชัดสำหรับปุ่มค้นหาและปุ่มเมนู |
| **4. "ดูแบบวางเป็นกองๆ ... ควรเพิ่มสีมีกรอบให้ข้อความ"** | ยกเลิกการวางข้อความเรียงต่อกันเป็นพรืดโดยไม่มีเส้นแบ่ง แต่จัดเนื้อหาทุกส่วนเข้าสู่ **ระบบการ์ดที่มีกรอบและสีพื้นหลังแยกสัดส่วน (Framed & Color-Coded Cards)** ได้แก่:<br>• **การ์ดหมวดหมู่หลัก (`.content-section-card`):** มีกรอบเส้นทึบสีเทาอ่อน (`border: 1px solid #E5E7EB`) มุมโค้ง `12px` บนพื้นหลังสีขาว<br>• **กล่องข้อความย่อย (`.news-card`, `.info-item`):** มีกรอบหรือพื้นหลังสีเทาอ่อน (`#F9FAFB`) พร้อม **แถบสีด้านซ้ายหนา `4px` (`border-left: 4px solid`)** แยกตามประเภทเนื้อหา (เหลืองทอง/เขียว/เทา) ทำให้แต่ละรายการมีกรอบและสีแบ่งชัดเจน ไม่กองรวมกันอีกต่อไป |
