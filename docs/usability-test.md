## ส่วนที่ 3: System Usability Scale (SUS) — 10 ข้อ

ให้ผู้ทดสอบตอบ (1 = ไม่เห็นด้วยอย่างยิ่ง … 5 = เห็นด้วยอย่างยิ่ง)

| # | ข้อความ | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|---|
| 1 | ฉันคิดว่าฉันจะใช้เว็บไซต์นี้บ่อย | | | | | |
| 2 | เว็บไซต์นี้ซับซ้อนเกินไป | | | | | |
| 3 | เว็บไซต์นี้ใช้งานง่าย | | | | | |
| 4 | ฉันต้องการความช่วยเหลือจากผู้เชี่ยวชาญในการใช้เว็บนี้ | | | | | |
| 5 | ฟังก์ชันต่าง ๆ ของเว็บไซต์ทำงานได้ดีสอดคล้องกัน | | | | | |
| 6 | เว็บไซต์นี้มีความไม่สอดคล้องกัน (inconsistent) มาก | | | | | |
| 7 | ฉันคิดว่าคนส่วนใหญ่จะเรียนรู้การใช้เว็บนี้ได้เร็ว | | | | | |
| 8 | เว็บไซต์นี้ใช้งานยาก (cumbersome) | | | | | |
| 9 | ฉันรู้สึกมั่นใจในการใช้เว็บไซต์นี้ | | | | | |
| 10 | ฉันต้องเรียนรู้หลายอย่างก่อนจะใช้เว็บนี้ได้ | | | | | |

**การคำนวณ SUS:**
- ข้อคี่ (1,3,5,7,9): คะแนน = ตอบ - 1
- ข้อคู่ (2,4,6,8,10): คะแนน = 5 - ตอบ
- รวมทั้ง 10 ข้อ → คูณ 2.5 → ได้คะแนน 0–100
- **เกณฑ์: ≥ 68 = ผ่าน (Acceptable)**
