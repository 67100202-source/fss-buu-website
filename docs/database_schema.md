# โครงสร้างฐานข้อมูลและข้อมูลจริงจากเว็บไซต์คณะวิทยาศาสตร์การกีฬา (`https://fss.buu.ac.th/`)

เอกสารฉบับนี้สรุปข้อมูลจริงที่ดึงมาจากเว็บไซต์ **[คณะวิทยาศาสตร์การกีฬา มหาวิทยาลัยบูรพา (`https://fss.buu.ac.th/`)](https://fss.buu.ac.th/)** เพื่อนำมาจัดทำเป็นฐานข้อมูลจริง (Real Database) ตามข้อกำหนดเทคนิคของโปรเจค โดยจัดเตรียมไว้ให้พร้อมใช้งานทั้งในรูปแบบ **SQL (`fss_buu_database.sql`)** สำหรับ SQLite / MySQL / PostgreSQL / Supabase และ **JSON (`fss_buu_database.json`)** สำหรับ Firebase / MongoDB / Node.js API

## 4. ข่าวประชาสัมพันธ์ ข่าวกีฬา 5 ข่าว ทุนการศึกษา และผลงานรางวัล (`news_articles`, `scholarships`, `achievements`)

- **ข่าวสารและกิจกรรมคณะ (5 รายการ):**
  1. เปิดพื้นที่ส่วนกลาง **“FSS Co-Working Space”** ณ ห้องกิจกรรม ชั้น 1 ขยายเวลาถึงเที่ยงคืน (15 ก.ย. 2569)
  2. กิจกรรม **“รุ่นพี่ พบรุ่นน้อง”** แนะแนวทางอาชีพและตลาดแรงงานอุตสาหกรรมกีฬา สุขภาพ และฟิตเนส (16 ก.ย. 2569)
  3. งานแสดงมุทิตาจิตแด่ **“รศ.ดร.ธนิดา จุลวนิชย์พงษ์”** ในโอกาสเกษียณอายุราชการ ประจำปี พ.ศ. 2569 (15 ก.ย. 2569)
  4. ร่วมงานวันคล้ายวันสถาปนามหาวิทยาลัยบูรพา ครบรอบ 71 ปี ประจำปี พ.ศ. 2569 (24 ก.ย. 2569)
  5. พิธีลงนามความร่วมมือทางวิชาการ (MOU) ร่วมกับ **Danang Sport University** สาธารณรัฐสังคมนิยมเวียดนาม ณ ห้องประชุม FSS-605 (11 พ.ย. 2567)
- **ข่าวกีฬาและการแข่งขันครบ 5 ข่าว (ตามเกณฑ์ประเมินข้อ 4):**
  1. **นายเกียรติศักดิ์ สิงหพงษ์** นิสิตชั้นปีที่ 1 สาขาวิชาวิทยาศาสตร์การออกกำลังกายและการกีฬา คว้ารางวัลชนะเลิศการแข่งขันรถจักรยานยนต์ทางเรียบ รายการ **Suzuka 4 Hours Endurance Japan รุ่น ST 600** ณ ประเทศญี่ปุ่น
  2. ทัพนักกีฬานิสิต ม.บูรพา คว้าเหรียญรางวัลในการแข่งขันกีฬามหาวิทยาลัยแห่งประเทศไทย ครั้งที่ 48 **“ดอกจานบ้านเชียงเกมส์”** ณ มรภ.อุดรธานี
  3. ศูนย์ปฏิบัติการ **BUU House** ขับเคลื่อนการจัดการแข่งขันและสื่อสารมวลชนในศึกเบสบอลและคริกเก็ตชิงแชมป์ประเทศไทย
  4. การแข่งขันกีฬาภายใน **“Sport Science Games”** เสริมสร้างทักษะการจัดการแข่งขันจริงและความสามัคคีระหว่างชั้นปี
  5. คณะวิทย์กีฬา ม.บูรพา ผนึกกำลังจัดงานวิ่ง **“BUU Night Run”** และประเพณีวิ่งเขาสามมุข (8 กรกฎ)
- **ทุนการศึกษาและทุนวิจัย (`scholarships`):**
  1. **ทุนสนับสนุนการทำวิจัยดุษฎีนิพนธ์ บัณฑิตวิทยาลัย ม.บูรพา** (ทุนละ `10,000 บาท` — อ้างอิงข่าวรางวัลของ นายภาคภูมิ พิลึก นิสิตปริญญาเอก)
  2. **โครงการผู้มีความสามารถพิเศษทางกีฬา (โครงการช้างเผือก) ปีการศึกษา 2569**
  3. **ทุนส่งเสริมการศึกษาสำหรับนิสิตผู้มีศักยภาพและนิสิตจิตอาสา คณะวิทยาศาสตร์การกีฬา**
