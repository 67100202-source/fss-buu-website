ส่วนที่ 2: ภารกิจ (Task-based Testing)

ให้ผู้ทดสอบทำภารกิจ (ไม่บอกวิธี) บันทึกเวลา/ความสำเร็จ/ข้อผิดพลาด

T1: หา "ปฏิทินกิจกรรม" ของเดือนตุลาคม 2569 → เป้าหมาย: เจอภายใน 3 คลิก, ≤ 30 วิ
T2: ค้นหาอาจารย์ "ดร.จิดาภา ศิริวรรณ์" ด้วยช่องค้นหา → เป้าหมาย: เจอชื่อ + สาขาวิชา, ≤ 20 วิ
T3: อ่านข่าวล่าสุด 1 ข่าว แล้วแชร์ไป LINE → เป้าหมาย: อ่าน + กดแชร์, ≤ 45 วิ
T4: กรอกแบบฟอร์มติดต่อ (สมัครกิจกรรม) แล้วส่ง → เป้าหมาย: ส่งสำเร็จ + เห็นข้อความยืนยัน, ≤ 60 วิ
T5: สลับภาษาเป็น English แล้วกลับเป็น Thai → เป้าหมาย: เมนู/เนื้อหาเปลี่ยน, ≤ 10 วิ
T6: (Admin) ล็อกอิน → เพิ่มข่าวใหม่ → ออกจากระบบ → เป้าหมาย: CRUD สำเร็จ, ≤ 90 วิ
#ภารกิจสำเร็จ? (✓/✗)เวลา (วิ)ข้อผิดพลาด/หมายเหตุ
T1หาปฏิทินกิจกรรม ต.ค. 2569
T2ค้นหาอาจารย์
T3อ่านข่าว + แชร์ LINE
T4กรอกแบบฟอร์มติดต่อ
T5สลับภาษา TH/EN
T6Admin CRUD
เกณฑ์สำเร็จ: T1–T5 สำเร็จ ≥ 80%, T6 สำเร็จ 100%

ส่วนที่ 3: System Usability Scale (SUS) — 10 ข้อ

ให้ผู้ทดสอบตอบ (1 = ไม่เห็นด้วยอย่างยิ่ง … 5 = เห็นด้วยอย่างยิ่ง)

#ข้อความ12345
1ฉันคิดว่าฉันจะใช้เว็บไซต์นี้บ่อย
2เว็บไซต์นี้ซับซ้อนเกินไป
3เว็บไซต์นี้ใช้งานง่าย
4ฉันต้องการความช่วยเหลือจากผู้เชี่ยวชาญในการใช้เว็บนี้
5ฟังก์ชันต่าง ๆ ของเว็บไซต์ทำงานได้ดีสอดคล้องกัน
6เว็บไซต์นี้มีความไม่สอดคล้องกัน (inconsistent) มาก
7ฉันคิดว่าคนส่วนใหญ่จะเรียนรู้การใช้เว็บนี้ได้เร็ว
8เว็บไซต์นี้ใช้งานยาก (cumbersome)
9ฉันรู้สึกมั่นใจในการใช้เว็บไซต์นี้
10ฉันต้องเรียนรู้หลายอย่างก่อนจะใช้เว็บนี้ได้
การคำนวณ SUS: ข้อคี่ (1,3,5,7,9): คะแนน = ตอบ - 1; ข้อคู่ (2,4,6,8,10): คะแนน = 5 - ตอบ; รวม 10 ข้อ → คูณ 2.5 → ได้คะแนน 0–100; เกณฑ์: ≥ 68 = ผ่าน
